This guide walks you through everything you need to send your first message with SocketFlow. By the end you will have a running TCP server that handles inbound messages and echoes them back, a client that connects, sends a message, and receives the response, and a taste of path-based routing. Each step builds on the previous one, and every code block is ready to run as-is.

<Steps>

  <Step title="Install SocketFlow">
    SocketFlow is published on PyPI and has no required dependencies. Install it with pip:

    ```bash
    pip install socketflow
    ```

    That is all. No C extensions, no transitive packages — just the Python standard library.
  </Step>

  <Step title="Create a server">
    Create a file called `server.py`. The server listens on `127.0.0.1:8080`, registers a handler for every inbound message, and blocks until you press Ctrl-C.

    ```python
    from socketflow import TcpServer, EventType

    # Create the server
    server = TcpServer(
        host="127.0.0.1",
        port=8080,
        keepalive_interval=30.0,
        keepalive_max_missed=3,
        compress=True,
    )

    # Register a handler for every message that has no path
    @server.event(EventType.Server.MESSAGE)
    def handle_message(data):
        print(f"Received: {data.data}")
        return "Response from server"

    # Start the server in the background, then block
    server.start()
    server.wait()  # Ctrl-C to stop
    ```

    `server.start()` launches the acceptor thread and returns immediately. `server.wait()` blocks the main thread so the process stays alive. The handler receives a `MessageReceivedData` object — the payload your client sends is in `data.data`.

    <Tip>
      You can collapse both calls into one with `server.start_and_wait()`, which starts the server and then blocks — a handy shortcut for simple scripts.
    </Tip>
  </Step>

  <Step title="Connect a client">
    Create a second file called `client.py`. The client connects to the server, sends a message, waits for the response, then disconnects cleanly.

    ```python
    from socketflow import TcpClient, EventType

    # Create a client that mirrors the server's settings
    client = TcpClient(
        host="127.0.0.1",
        port=8080,
        keepalive_interval=30.0,
        keepalive_max_missed=3,
        compress=True,
    )

    # Register a handler for unsolicited server-to-client messages
    @client.event(EventType.Client.MESSAGE)
    def handle_message(data):
        print(f"Server pushed: {data.data}")

    # Connect — completes the security handshake automatically
    client.connect()

    # Send a message and wait for the server's return value
    response = client.send("Hello, Server!", wait_response=True)
    print(f"Server response: {response.data}")

    # Clean up
    client.disconnect()
    ```

    Run the server first, then the client in a second terminal. You should see `Received: Hello, Server!` in the server window and `Server response: Response from server` in the client window.
  </Step>

  <Step title="Add path-based routing">
    Instead of a single catch-all handler, you can route messages to dedicated functions using URL-style paths. Update `server.py` to add an echo route:

    ```python
    from socketflow import TcpServer, EventType

    server = TcpServer(host="127.0.0.1", port=8080, compress=True)

    # Handles messages sent to the "/echo" path
    @server.path("/echo")
    def handle_echo(data):
        print(f"Echo request: {data.data}")
        return data.data  # Send the payload straight back

    # Fallback for messages sent without any path
    @server.event(EventType.Server.MESSAGE)
    def handle_default(data):
        print(f"Default handler: {data.data}")
        return "ok"

    server.start_and_wait()
    ```

    On the client side, pass `path="/echo"` to `send`:

    ```python
    from socketflow import TcpClient

    client = TcpClient(host="127.0.0.1", port=8080, compress=True)
    client.connect()

    # This message is routed to the /echo handler
    response = client.send("ping", path="/echo", wait_response=True)
    print(f"Echo: {response.data}")  # Echo: ping

    # This message falls through to the default handler
    client.send("fire and forget")

    client.disconnect()
    ```

    Path strings are arbitrary — choose whatever naming convention makes sense for your application.
  </Step>
