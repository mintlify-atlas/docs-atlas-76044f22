## Why SocketFlow

SocketFlow is built for developers who need reliable, high-performance TCP messaging without pulling in a dependency tree.

<CardGroup cols={3}>
  <Card title="Zero Dependencies" icon="shield-check">
    Runs entirely on the Python standard library. Install it and nothing else changes.
  </Card>
  <Card title="Event-Driven" icon="bolt">
    Decorator-based handlers for messages, connections, and errors — no polling loops.
  </Card>
  <Card title="Path Routing" icon="route">
    Route messages to specific handlers using path strings, just like HTTP routes.
  </Card>
  <Card title="TLS & mTLS" icon="lock">
    One-way and mutual TLS with client certificate verification built in.
  </Card>
  <Card title="Compression" icon="compress">
    zlib, lzma, bz2, gzip, zstd, and brotli codecs with per-message negotiation.
  </Card>
  <Card title="Observability" icon="chart-bar">
    Structured logging and Prometheus-compatible metrics out of the box.
  </Card>
</CardGroup>

## Get Running in 60 Seconds

<Steps>
  <Step title="Install SocketFlow">
    ```bash
    pip install socketflow
    ```
  </Step>
  <Step title="Create a server">
    ```python server.py
    from socketflow import TcpServer, EventType

    server = TcpServer(host="127.0.0.1", port=8080)

    @server.event(EventType.Server.MESSAGE)
    def on_message(data):
        print(f"Received: {data.data}")
        return "pong"

    server.start_and_wait()
    ```
  </Step>
  <Step title="Connect a client">
    ```python client.py
    from socketflow import TcpClient

    client = TcpClient(host="127.0.0.1", port=8080)
    client.connect()

    response = client.send("ping", wait_response=True)
    print(f"Server replied: {response.data}")

    client.disconnect()
    ```
  </Step>
  <Step title="Explore further">
    Check out the [Core Concepts](/concepts/server) to understand the server lifecycle, or jump straight to the [API Reference](/api/tcp-server) for complete parameter documentation.
  </Step>
</Steps>
